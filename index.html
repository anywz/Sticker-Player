Importe seu print
Escolha uma imagem da sua galeria. O processamento acontece neste aparelho.

1. Ajustar o recorte

A detecção automática é uma estimativa inicial. Use os controles para alinhar o recorte ao contorno real. A área externa será removida com transparência.

2. Conferir transparência

Troque o fundo para conferir se a área externa está transparente.

O arquivo exportado é PNG RGBA. Os pixels fora da máscara recebem alfa zero; as cores e os pixels internos vêm do print original.

Sticker Player · Processamento local · Suas imagens não são enviadas a um servidor.
